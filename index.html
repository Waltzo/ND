보호자 설정

설정을 여는 동안에는 시선 입력이 멈춥니다. 바꾼 값은 바로 적용됩니다.

소리와 글

확인 방식

확인 방식

깜빡임은 마우스 클릭이나 스페이스바로 대신합니다. 빠르게 두 번 누르세요.

고를 칸을 보면서 눈을 또렷하게 두 번 감았다 뜨세요.

기가지니

지니야 칸을 확인하면 호출어를 먼저 말하고, 잠시 기다린 뒤 쓴 말을 읽습니다. 소리가 켜져 있어야 합니다.

입력 방식

입력 방식

카메라는 얼굴을 보고 시선과 깜빡임을 읽습니다. 영상은 이 기기 안에서만 쓰고, 어디에도 보내거나 저장하지 않습니다.

태블릿을 옮기면 자세를 다시 확인하고 가운데 한 점만 보면 됩니다. 그래도 잘 맞지 않으면 다시 보정을 누르세요. 9칸을 차례로 봅니다.

깜빡임과 호출음

이보다 짧게 감으면 저절로 나온 깜빡임으로, 길게 감으면 쉬는 것으로 보고 넘어갑니다.

눈을 이 시간 넘게 감고 있으면 어느 화면에서든 호출음이 울립니다. 소리를 꺼 두어도 울립니다. 0으로 두면 끕니다.

시안 시험용

마우스 방식에서는 포인터가 시선을 대신합니다.

자주 쓰는 단어

자주 쓰는 단어 등록8개

여기서 고치면 자판에 바로 반영되고 이 기기에 저장됩니다.

입력 규칙

  1. 묶음 칸의 작은 9칸은 열었을 때 글자가 놓이는 자리입니다.
  2. 자음은 글자를 확인하면 바로 입력되고 처음 화면으로 돌아옵니다.
  3. 모음은 글자를 고른 뒤 입력 칸을 확인해야 들어갑니다. ㅗ, ㅏ, 입력은 ㅘ.
  4. 쌍자음 칸을 확인하면 ㄱ은 ㄲ, ㅏ는 ㅑ, ㅗ는 ㅛ처럼 바뀝니다.
  5. ㅐ는 ㅏ ㅣ, ㅔ는 ㅓ ㅣ, ㅢ는 ㅡ ㅣ, ㅝ는 ㅜ ㅓ 순서로 고릅니다.
  6. 숫자는 0에서 시작해 더하고 빼서 맞춘 뒤 입력 칸으로 넣습니다. 0부터 999까지 됩니다.
  7. 지니야 칸은 쓴 말을 기가지니에게 명령으로 전합니다. 쓴 말이 없으면 호출어만 말합니다.
  8. 묶음 안에서는 가운데가 뒤로입니다.
